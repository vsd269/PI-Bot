# PI Bot 0.3.107

本次正式发布汇总 0.3.102–0.3.107 的全部更新，重点改善侧栏整理、长期记忆检索、消息交互与执行反馈。

## 侧栏分类与排序

- 新增默认“群组聊天”分类与自定义部门，Bot 和群聊可以归入同一个部门，支持会话数量显示、折叠、改名和删除。删除部门只移除分类，保留会话与聊天记录。
- 左上角加号可创建空部门；会话右键菜单新增“移至部门”。鼠标悬停会话行时显示三个点，点击即可打开与右键相同的操作菜单。
- 支持拖动 Bot 和群聊调整顺序，也可跨部门移动。分类、排序与折叠状态持久保存；主机器人保持固定，置顶会话排在各自分类前方。
- 折叠部门里的会话仍可通过搜索找到。分类保存失败时撤回本次改动，避免覆盖同时到达的聊天内容；备份与恢复保留分类配置。

## 记忆检索与历史回看

- 长期记忆先返回简短索引，再根据稳定引用读取需要的单条正文，减少无关内容占用上下文。
- 历史消息检索支持查看匹配位置的前后文，方便回看事情的来龙去脉。
- 保留私密 Bot 与记忆原有的访问范围限制。

## 消息表情与操作按钮

- 放大消息旁表情、回复、更多三个图标的实际图案，统一圆形悬停背景，保留原有点击区域、时间位置和窄窗口布局。
- 添加、切换表情即时显示，再次点击同一个表情即时移除；保存改在后台完成，不再等待整份会话返回。
- 连续操作按最终选择保存，旧刷新不会把表情改回去；私聊、群聊和不同消息分别处理。保存失败时恢复最近保存成功的状态并提示重试。
- 表情更新只刷新对应标记，保留消息内容、文字选区和已展开的工具记录。

## 回复状态与停止操作

- 修复“执行中”和“正在回复”重复显示的问题，同一任务的实时运行状态统一显示一份，保留结束、失败及中断记录。
- 私聊存在排队、启动、执行、待审批或等待队友交回的任务时，输入框右下角显示停止按钮，空输入框也能操作。
- 点击后立即显示正在停止并防止重复点击，调用任务中断接口；失败时提示重试，保留草稿与已有回复。
- 停止范围限定为点击时所在 Bot 的私聊任务，切换会话不会误停其他 Bot，也不影响该 Bot 的群聊工作。已经完成的文件修改不会因停止而撤销。

## 顶栏、滚动条与视觉细节

- 聊天内容可滚动到中间 Bot 按钮后方；顶栏使用透明渐变，边缘柔和淡出，改善消息被直线切断的感觉，适配浅色与深色模式。
- 保留窗口拖动、标题按钮、详情面板与侧栏调整；聊天查找放在顶栏下方，新消息定位避开顶栏遮挡。
- 左侧滚动条默认隐藏，鼠标进入侧栏后显示细线，移到滚动条上或拖动时加粗，移出侧栏后隐藏；调整分隔线拖动区域，避免遮挡滚动条。
- 管理员卡片保持顶部固定，其下方和列表底部都使用连续柔和渐隐；列表末尾预留滚动空间，最后一条会话可完整显示。
- 加深“群组聊天”和部门名称的文字颜色，随明暗模式切换。
- 修复密钥用途保存按钮文字折行、错位的问题。

## 下载与安装

请下载 **`local.pi-bot-0.3.107.piplug`**。`PI-bot-0.3.107.piplug` 为旧版更新识别保留的同内容文件，两者只需安装一个。源码另见 `PI-Bot-0.3.107-source.zip`，校验值见 `SHA256SUMS.txt`。

更新后请重载 PI Bot 插件或重启 PI Desktop。
