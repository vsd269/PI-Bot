# PI Bot 0.3.110 更新说明

本次合并 0.3.108～0.3.110 三次更新，包含：

- 修复长任务中出现“Request expired.”及回复显示延迟，优化大状态传输和管理员实时输出。
- 优化停止响应，群聊停止可同时处理成员任务与管理员规划，修复重复停止报错。
- 完善原生提问卡，支持多题、单选／多选、自定义回答、跳过与拒绝，回答后继续原任务。
- 支持 @ 群管理员，完善群系统提示的头像、名称与颜色，修复群聊和私聊未读标记混淆。
- 应用连接在启动后自动后台检查，恢复侧栏连接状态并保留原有 Bot 分配，无需先打开应用窗口。
- 修复“连接应用”长时间空白：账号、分类和目录独立加载，已有连接与缓存先显示，慢请求超时后可重试。
- 优化应用读取优先级、分页失败保留及晚到结果处理，避免聊天刷新阻塞页面或旧结果覆盖当前内容。
- 优化图片预览展开图标、折叠侧栏未读圆点等细节。

直接更新可沿用原有 Bot、聊天与配置，请勿先删除插件数据。应用预览不代表已授权，实际连接仍以账号和权限状态为准。

更新后请重载 PI Bot 插件或重启 PI Desktop。
