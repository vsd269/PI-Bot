# PI Bot 0.3.97

本版修复窗口控制图标、新建 Bot 开场内容和共享头像库报错。

- **窗口按钮**：放大最小化、最大化／还原和关闭图案。之前宿主给 SVG 写入了内联小尺寸，普通 CSS 调整没有改变实际图案大小；现在覆盖实际渲染尺寸，并保留原生按钮点击、最大化状态和还原图标。
- **新建 Bot 开场**：新建后马上显示按 Bot 名称与职责生成的本地问候和任务建议，不必等待模型。后台会根据名称、职责说明生成更具体的开场问题和 3 至 4 个选项；响应经过格式校验后才更新。若期间用户已经发消息、回答、改名或删除 Bot，就保留现有会话，不套用迟到的结果。
- **新建页头像库**：接通共享头像库读取与选择接口，修复点击“共享库”时报 `onLibrary is not a function` 并持续显示在页面顶部的问题。

## 验证范围与限制

回归覆盖宿主 SVG 内联尺寸覆盖、窗口按钮处理及最大化／还原图标、创建页共享头像选择、不同 Bot 职责的开场种子、模型返回校验、保存失败回滚，以及用户开始对话或 Bot 状态变化时丢弃迟到的个性化结果。完整回归在隔离浏览器和本地测试环境中运行，不代表已在实际 PI Desktop 中验收。后台开场个性化会调用该 Bot 所选模型一次；生成失败时保留本地开场卡片。

## 安装

桌面安装包：`PI-Bot-0.3.97.piplug`。旧版本安装包保留，本次不推送 GitHub。

更新后请重载 PI Bot 插件或重启 PI Desktop。
