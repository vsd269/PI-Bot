# PI Bot 0.3.105

本版整合侧栏分类、拖动排序与交互调整，以及记忆检索和界面细节修复。

- 侧栏新增“群组聊天”分类和自定义部门，支持会话数量、折叠、改名和删除。Bot 与群聊都能移入同一部门；删除部门只恢复默认分类，不删除会话。
- 右键菜单新增“移至部门”，会话行悬停时显示三个点，点击后打开同一份菜单。左上角加号中可新建空部门。
- Bot 和群聊支持拖动排序、拖入部门；排序与折叠状态会保存，重启后保留。主机器人固定在顶部，置顶会话保持在所在分类前方。
- 左侧列表、聊天区和详情面板统一滚动条尺寸：8px 操作宽度，通常为 2px 细线，悬停或拖动时为 6px，轨道透明；左侧位置更贴近边缘。
- 保存分类时依次写入，失败会撤回本次改动；不覆盖同时到达的聊天内容。部门折叠后仍能通过搜索找到会话。
- 记忆检索先返回简短索引，再按引用展开单条内容；历史搜索可连同前后文查看。保留现有 Bot 及私密记忆的可读范围。
- 修复密钥用途保存按钮文字折行、错位；长侧栏滚动时保留管理员顶部位置与渐隐衔接。
- 保留此前消息操作图标、表情即时反馈、回复状态去重及停止按钮修复。

## 验证

393 项自动化测试通过，1 项 Windows 符号链接权限测试跳过；脚本语法和版本一致性检查通过。浏览器界面验证了菜单入口一致性、Bot/群聊移动、失败回退、折叠搜索、拖动排序、重载保留、部门改名/删除、管理员固定及头像栏模式。

界面测试采用隔离数据和模拟宿主，不等同于在真实 PI Desktop 中完成全部模型与工具调用验收。

## 安装

导入 `local.pi-bot-0.3.105.piplug`，然后重载 PI Bot 插件或重启 PI Desktop。此安装包未发布到 GitHub。
