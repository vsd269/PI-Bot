# PI Bot 0.3.99

本版修复未回答开场卡片被自动作废的问题，并继续优化通话和聊天阅读体验。

- **开场卡片**：未选择、未主动跳过的卡片保持待回答；切换 Bot、打开设置、进行其他工作、重新读取数据及恢复备份都保留。同时修复旧版自动作废或备份中断的开场卡片；已回答或主动关闭的卡片不会被自动恢复。
- **通话浮条**：取代全屏语音面板，保留聊天区域；可展开文字记录，暂停／恢复聆听、结束通话或进入语音设置。本次通话记录显示最近 100 条，完整消息仍在原聊天中。
- **语音输入**：默认服务支持实时转写时，录音期间持续发送音频，停止后等待服务确认最终文字。其他服务保持文件转写，不擅自切换服务或模型；取消后的迟到结果不写入输入框。
- **工作经验**：从消息“…”→“工作经验”进入“查看工作经验”或“复盘经验”；没有消息时，可右键 Bot 列表进入。提案审批、失败提示及私密 Bot 共享确认继续保留。
- **消息表格**：圆角卡片、搜索行数、按列排序、悬停复制／CSV 下载／放大按钮；保留超过 100 行的数据，支持转义分隔符及单元格代码，导出时处理电子表格公式风险。
- **按钮与头像**：关闭左侧头像的悬停动作；最小化和关闭图案单独放大，最大化图案维持原尺寸，关闭悬停使用亮红底；工作区入口居中对齐，继续用于 PI Desktop 工作区和终端。

## 验证范围

使用隔离数据和模拟语音服务进行业务回归及 Playwright 界面检查，不改动用户的实时会话、模型或密钥。本轮没有使用真实云端语音账户进行麦克风端到端测速，实际转写速度仍受服务处理和网络影响。界面检查不能替代实际 PI Desktop 的原生窗口验收。

## 安装

桌面安装包：`PI-Bot-0.3.99.piplug`；保留旧版本。安装后重载插件或重启 PI Desktop。本轮未发布 GitHub。
