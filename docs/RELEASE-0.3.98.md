# PI Bot 0.3.98

本版让聊天阅读更舒服，也把经验和工具入口收得更紧凑。

- **窗口按钮**：最小化、最大化／还原和关闭图案缩小到与 Grok Bot 一致的 12px 规格，点击操作仍由 PI Desktop 处理。
- **语音按钮**：悬停时保持原来的颜色；语音对话图案改成更细密的波形纹理。
- **工作经验**：入口改为可展开的小标题，复盘按钮、待确认建议和状态放在里面；Bot 间记住展开状态。
- **工具记录**：改为紧凑胶囊入口，展开后仍可查看工具名和调用详情。
- **回复排版**：文字调整为 15px 并增加行距，同时改善标题、列表、引用和代码块的阅读层次。
- **工作区**：保留 PI Desktop 原生工作区入口，可继续打开宿主工作区与终端。

## 验证范围与限制

窗口、语音按钮、回复排版、工具记录和工作经验面板经过隔离 Playwright 界面测试；消息与学习业务回归也已运行。测试不代表已在实际 PI Desktop 中人工验收。

## 安装

桌面安装包：`PI-Bot-0.3.98.piplug`。旧版本安装包保留，本次不推送 GitHub。

更新后请重载 PI Bot 插件或重启 PI Desktop。
