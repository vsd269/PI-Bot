# PI Bot 0.3.96

本版集中修复附件传递，补充即时开场问候，并按参考界面调整提问卡片、输入区和顶部控件。

- **新建 Bot**：保存后立即显示问候和选项卡，不调用模型生成问候。可点击选项或输入自己的任务；已有 Bot 不重复补发问候。
- **提问卡片**：最大宽 560px、24px 圆角、细边线，无额外厚重阴影；字母选项与自定义回答保持可用。直接发送附件或新任务时，过时的开场卡片收起。
- **图片与文件**：群聊管理员及规划模式管理员私聊现在通过 PI 原生会话接收真实附件，使用各自会话的安全暂存目录；转发后重新暂存，不放宽会话隔离。私聊过程原位更新，不再遗留持续转圈的预览行；失败提示保留具体原因。
- **执行可靠性**：原生提交前保存领取状态；提交后保存失败时请求停止该轮；重启后提示人工核对，不盲目重放附件任务。
- **输入区**：最大宽 960px；附件放在输入框上方，立即显示完整比例缩略图。文档、音频和视频保留类型卡片；添加状态与错误就地显示，可重试和移除。
- **顶部与详情栏**：按钮整体下移约 4px，中间小尖角只在悬停、键盘聚焦或详情展开时出现。右侧工具按钮为 34px 圆形、16px 图标、10px 间距；窗口控制图标加大，保留宿主点击行为。工作区展开时的暗色接缝使用当前主题背景，保留宿主拖动区域。

## 验证范围与限制

运行单元回归、语法和版本检查、隔离浏览器中的附件、顶栏、侧栏与问题卡回归。附件检查包含真实图片解码、上传失败重试、上传中移除、切换聊天取消，以及管理员私聊从发送到最终回复的路径。另使用本地 PI Desktop SDK 的真实附件预处理函数验证会话目录、图片字节和长文附件。

这些检查不等同于已在用户实际运行的 PI Desktop、真实模型或第三方账号中完成验收。模型支持视觉时才能理解图片；明确标记为纯文本的模型沿用本地 OCR，Windows OCR 需要相应语言组件，其他系统不提供该本地 OCR。未知模型的视觉能力仍需实际验证。
