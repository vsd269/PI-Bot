# PI Bot 0.3.93

新增“应用”连接页，按参考界面的源码尺寸适配分类分组、应用图标、双列卡片、搜索、更多分类与分页。保留 0.3.92 的侧栏宽度拖动、展开收起过渡和顶栏拖窗区域修复。

## 使用方式

1. 点击左下角“连接应用”。
2. 点击 Composio 卡片的“配置”（配置完成后是“已包含”），填写自己的 Composio 项目 API Key。也可从“已连接”页面打开“Composio 项目设置”。
3. 点击应用的“连接”，生成链接后打开官方授权页面，完成登录和授权。
4. 返回插件检查连接，勾选可使用该账号的 Bot，或全选，点击“保存 Bot 分配”。
5. Bot 使用 `list_app_tools` 发现已分配账号与工具，使用 `call_app_tool` 调用。修改类调用标记为高风险，遵守 PI 原生审批设置。

每位用户使用自己的 Composio 项目和额度；插件作者无需运行公共授权服务器。第三方服务及 Composio 的费用、权限和地区可用性由各自服务决定。部分应用需要在自己的 Composio 控制台创建并启用 Auth Config，连接表单提供对应 ID 字段。

密钥、会话标识和 Bot 分配一起保存在 Windows 当前用户加密的密钥库中，不写入普通团队备份或模型上下文。跨电脑迁移需另外导出密码加密的密钥迁移文件。移除本机项目配置不会撤销云端已有授权；需要时先断开账号或前往服务控制台撤销。

## 范围与验证

- 目录与账号接入 Composio REST API v3.1；支持搜索、分类、分页、多账号和无需账号授权的工具。
- 未配置项目时展示应用预览，卡片不代表已连接。配置后从用户项目读取真实目录和账号，项目实际目录可能与示例截图不同。
- 原有 GitHub PAT、本地/远程 MCP 接入保留。独立订阅服务、云端事件触发与企业模块不在本次范围内。
- 已验证：模拟服务下的授权流程、加密写入失败回退、账号与工具归属、跨 Bot 隔离、撤权竞态、停止与删除校验、不自动重试写操作、真实 Windows DPAPI 加密读回；浅色/深色/窄窗口及侧栏布局测试。
- 尚未验证：用户真实 Composio 项目与每家第三方服务的登录、实际外部写操作；安装后通过鼠标拖动真实 PI Desktop 窗口。没有使用或要求用户在聊天中提供真实密钥。

更新后请重载 PI Bot 插件或重启 PI Desktop。
