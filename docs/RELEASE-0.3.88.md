# PI Bot 0.3.88：DS Bot 0.2.4 功能适配候选版

日期：2026-10-30（Asia/Shanghai）。在本地 0.3.87 候选代码基础上继续适配，包含其任务派发可靠性补丁。插件 ID 仍为 `local.pi-bot`。本版尚未发布到 GitHub/插件市场，未替换正在运行的 PI Desktop 插件。

## 新功能与入口

| 功能 | 在哪里使用 | 行为 |
| --- | --- | --- |
| 本群全部停止 | 点击群聊标题 → 群详情 → 全部停止 | 请求中止管理员规划与本群成员的活跃/排队任务，清空待交接队列；迟到的旧轮次不能继续派发 |
| 保存工作方法为 Skill | Bot 私聊底部 → 复盘经验 → 查看并确认 | 根据已完成的任务生成可复用方法，确认后保存到能力库并分配给提出建议的 Bot |
| 项目规则建议 | 同一复盘入口中的 AGENTS.md 建议 | 先显示修改前后内容；确认后写入已核对项目的 AGENTS.md；目录、成员或原文变化时拒绝覆盖 |
| 低频自动复盘 | 设置 → 通用 → 工作经验 | 默认关闭；开启后仅较长任务结束且空闲约 10 分钟触发，每个 Bot 约 12 小时最多一次，会额外调用模型 |
| 响应式侧栏 | 拖动左侧分隔线、折叠按钮、调整窗口宽度 | 拖至阈值吸附头像栏；窄窗先收起右侧详情，再折叠左栏；保留手动宽度和折叠偏好 |
| 轻量 Office 工具 | 设置 → 通用 → Office 文档 → 检查 Office 环境；也可直接让执行 Bot 处理文件 | Bot 调用 get_office_tools 获得 CLI/环境/说明，实际命令经 PI 原生工具执行 |

停止操作不回滚已完成的文件写入或其他外部效果；宿主没有确认的中止请求会提示核对。已经发出的无法取消的非工具模型请求可能仍消耗用量，但旧结果不会触发新的本群派发。不停止无关私聊或其他群聊。

经验复盘读取所选 Bot 的少量已完成任务摘要和该任务项目的 AGENTS.md，并发送到其所选模型服务；开启前请按你的资料使用要求决定。没有新的已完成执行任务时不会生成提案。仅管理员规划文字回复没有对应执行任务，暂不纳入此入口。提案不是事实验收，用户仍需审阅内容。

## Office 范围

| 格式 | 已接入 | 额外环境 |
| --- | --- | --- |
| Word .docx | 读取段落/表格/字段/批注，定点替换/插入/表格单元格编辑，结构检查 | 独立 Node.js 20+ |
| PowerPoint .pptx | 页面/元素清单、结构布局检查，页面重排/复制/清理 | 独立 Node.js 20+；肉眼排版验证还需另有渲染器 |
| Excel .xlsx | 工作表清单、公式及缓存值读取，OOXML 解包/重新打包 | 独立 Node.js 20+；高级编辑需另有获批库，公式重算需独立计算环境 |

环境来自当前可用的独立 Node 或 PATH；可用 `PI_BOT_OFFICE_NODE` 指定 node 的绝对路径。PI/Electron 主程序不会被当作 Node 解释器。默认写新文件，原生会话权限继续生效。环境检查不安装依赖、不打开用户文档、不发网络请求。

未打包 Python、LibreOffice、PDF 转换器和 Office 排版引擎；不承诺完整 Excel 公式重算、视觉还原或旧 .doc/.ppt/.xls 二进制格式编辑。

## 本版未包含

- 私密 Bot：PI 原生工具、会话和子任务的执行拦截覆盖尚未在真实宿主验证；没有添加不能保证隔离的开关。
- Deep View 整体替换：继续使用已经适配的现有交互卡片。
- 独立浏览器、宿主安装器更新或 PI 客户端二进制修改。
