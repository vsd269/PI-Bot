# PI Bot 0.3.89：私密 Bot（插件层保护）

日期：2026-10-31（Asia/Shanghai）。基于本地 0.3.88 测试版补充，继承之前的群聊全部停止、经验提案、侧栏和 Office 工具。插件 ID 仍为 local.pi-bot；旧版本包保留。本版合并发布 0.3.87～0.3.89 的改动；不自动安装，插件市场需单独提交。汇总见 GITHUB-RELEASE-0.3.89.md。

## 怎么开启

1. 选择一位普通执行 Bot，点击顶部会话名称，再点击“编辑会话”进入机器人设置。
2. 在“工作文件夹”设置独立的、已存在的目录；它不能与 PI 当前工作区、PI Bot 数据目录、其他 Bot、群聊或已删除私密 Bot 的受保护目录相同、互相包含。
3. 如果该 Bot 已经加入群聊，先把它从群聊移除；等待它及相关派发任务结束。
4. 打开“隐私 → 私密 Bot”。修改自动保存，重新打开设置仍保留。切换时开始新的私聊会话，原记录保留。

主 Bot 不能开启私密。开启后，用户仍能看见、管理和与它聊天；其他 Bot 通过插件工具看不到它的资料、活动、聊天和记忆，也不能修改它的设置/能力或向它派发任务。新建群聊及添加群成员时不列出私密 Bot；后端同样拒绝绕过界面的添加。

## 共享与记忆

- 私密 Bot 的记忆仍保存在自己的记忆范围内，不会写入团队/群聊记忆；新增私密记忆日志独立保存。
- 管理员的 recall、remember、forget 工具同样不能读取或修改它的记忆。
- 私密 Bot 不会自动向其他 Bot 发送消息，也不能直接保存共享 Skill。需要共享时，由用户明确选取内容并手动转交。
- “复盘经验”仍可生成提案，用户能预览并决定；私密 Bot 的 Skill 提案在确认按钮前明确提示：确认后进入所有 Bot 可读的共享能力库。拒绝不写入共享库。
- 启用私密不能撤回此前已进入公共聊天、记忆、Skill、原生会话或备份的内容；建议敏感工作从新 Bot 开始。

## 删除、备份和目录异常

删除后的聊天/记忆归档保留私密标记，工作目录继续避免被公开 Bot/群聊重新使用。复制私密 Bot 只复制用户明确操作的职责、模型等设置，新副本不继承工作目录、私聊会话和记忆，并默认关闭私密。

备份保留私密标记，非法标记或私密成员加入群聊的备份会被拒绝。备份包含用户可管理的私密内容，请用户妥善保管，不能把普通配置备份视为加密保险箱。

私密目录失效时任务报错并停止，绝不回退到共享工作区。后来把 PI 工作区切进私密目录时，公开 Bot 的新会话也会拒绝启动。保存失败会恢复原私密状态和会话映射。

## 保护边界

这是 PI Bot 自有数据、目录配置和插件工具的应用层保护。尚未在真实 PI Desktop 中证实对原生文件、shell/命令、MCP、会话/子任务工具的全量执行拦截，不能承诺其他原生工具无法读到磁盘上的私密文件，也不是操作系统权限或进程沙箱。

因此本版不声称与 DS Bot 0.2.4 的全链路私密隔离完全相同。宿主原生工具依然遵循 PI Desktop 的权限设置；涉及高敏感文件时还需宿主沙箱或系统级访问控制。

## 安装与验收

通过 PI Desktop 导入 local.pi-bot-0.3.89.piplug，然后重载插件或重启 PI Desktop。本次没有触碰用户已安装的插件、聊天、密钥或模型配置。

本地验证记录见 PRIVACY-0.3.89-TEST-REPORT.md。隔离浏览器测试使用模拟宿主；真实 PI Desktop 与模型联调待用户安装后验收。

## 插件市场更新说明草稿

新增私密 Bot：普通执行成员可在设置中开启，需独立工作目录且不加入群聊。限制其他 Bot 通过插件读取其聊天、记忆和任务，阻止自动共享；经验 Skill 提案仍需用户预览确认。完善私密目录异常、删除归档、备份及保存失败保护。本功能属于插件层保护，原生工具仍由 PI Desktop 权限控制。更新后请重载插件或重启 PI Desktop。
