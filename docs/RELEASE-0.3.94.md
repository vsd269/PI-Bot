# PI Bot 0.3.94

本版修复应用连接的持续报错体验，以及两侧栏伸缩位置悬停时线条过粗的问题。

## 应用连接

0.3.93 的通用 RPC 错误处理先向聊天区写入横幅，随后应用页面再显示一次错误；关闭弹窗后横幅仍然保留。授权检查每四秒继续轮询，网络错误后也不停止，造成反复报错。本版由应用页面单独展示错误，自动检查失败后暂停，用户可在完成授权后点击“我已授权，检查连接”，也可刷新应用。

读取失败不清除已有连接、项目密钥和 Bot 分配。断开账号时先撤销本机访问的既有规则保持不变。错误区分超时、无法连接、HTTP 状态码、限流、格式错误和响应超限；不输出密钥、授权响应正文或原始网络错误。所有修改类操作继续禁止自动重试，避免重复发送邮件等操作。

此修复处理已确认的提示泄漏、轮询与错误误分类。截图中的原始服务失败原因无法从统一报错反推；真实 Composio 项目和第三方账号尚未联调，服务或网络真实故障仍会在应用页显示具体分类，不会被当作成功。

## 侧栏

对照上游开源组件的透明手柄设计，左侧 12px 热区不额外绘制悬停色块；右侧 6px 热区仅画 1px 悬停提示。键盘聚焦有 2px 提示。保留拖动、连续调整、折叠、宽度记忆、窄窗口和动画。

## 验证与安装

使用隔离模拟项目测试，不读取用户真实密钥，不修改真实第三方应用。运行完整单元回归、脚本语法/版本检查、应用页和全界面无头浏览器回归，并校验实际插件包内容。验证结果以本次执行报告为准。

安装 local.pi-bot-0.3.94.piplug 后请重载 PI Bot 插件或重启 PI Desktop。此前发布包不覆盖；本次尚未推送 GitHub。
