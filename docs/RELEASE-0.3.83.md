# PI Bot 0.3.83

本版以已发布的 0.3.82 为基准，修复附件读取、长消息全文和输入框文件粘贴。日期：2026-10-22（北京时间）。此版本待用户确认后再发布 GitHub。

## 修复内容

- 附件按 Bot 原生会话存放，避免出现 `Attachment path is outside the session roots`。支持新旧上传文件、图片缓存，以及转交到其他成员的附件。
- 长消息的完整文本同样放入所属会话可读目录；原始全文不丢弃。群聊将长资料分派给成员时保留用户原始资料附件。
- 超出渲染桥单次大小限制的中文消息通过分段传输；短消息和普通附件上传分段不增加额外流程。
- “显示全部”按钮继承消息气泡文字颜色，并保留展开状态，避免黑底按钮不可见或后台刷新后突然折叠。
- 输入框支持 Ctrl+V 粘贴剪贴板提供的 TXT、Word、图片和其他文件；多文件排队添加，保留原有加号入口。剪贴板里只有普通文字时仍正常粘贴文字。
- 只有附件时也可发送。上传期间显示进度并阻止提前发送；切换会话不会将附件放进另一会话。

## 使用与确认

安装 `local.pi-bot-0.3.83.piplug` 后重载插件或重启 PI Desktop，原有 Bot、群聊、能力与语音配置沿用现有数据。无需额外调整会话权限。

建议用之前失败的 TXT 重试，再发送一段两万字以上、三万两千字以内的文字，确认 Bot 能读取最后一段；在资源管理器复制 TXT 或 Word 文件，在聊天输入框按 Ctrl+V，确认出现附件标签。

消息现有 32,000 字符、最多 8 个附件、单文件 20 MB 的限制保留。长消息为提高界面性能默认折叠，点击“显示全部”即可展开全文。文档的分析能力仍取决于所选模型和 PI 原生文件工具；本版不新增 Word/PDF 转换引擎。

## 验证边界

新增回归覆盖附件字节完整性、跨会话转交、原文末尾保留、长中文请求分段和无效分段拒绝。浏览器测试通过真实输入框和附件上传后端验证文件粘贴、上传反馈、群聊/单聊、仅附件发送、加号入口、明暗主题与长文展开。

使用本地 PI Desktop SDK 源码中的实际附件校验函数复现原错误，再验证修复路径能通过，且其他会话仍拒绝直接读取该会话附件。安装包另用当前 PI host-core 在隔离资料目录验证。

自动化粘贴测试使用浏览器 ClipboardEvent 文件事件，不覆盖用户系统剪贴板。未使用用户的模型账号发起真实推理；实际文件阅读与 Windows 系统 Ctrl+V 的最终体验需用户安装后确认。尚未上传 GitHub 或插件市场，也没有修改用户正在使用的插件资料。
