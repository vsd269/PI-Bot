# PI Bot 0.3.82

日期：2026-10-21（北京时间）

基于 GitHub 正式版 0.3.81，参照 DeepSeek-Bot 0.2.0 迁移群聊独立记忆、消息时间与回复耗时、通用交互卡片，同时修复原生侧栏入口留空。本项目是独立维护的 PI Desktop 适配版，感谢上游作者的开源工作。

## 群聊独立记忆

- 入口：打开一个群聊，点击聊天顶部的群名称，在右侧详情中点击“群聊记忆”。
- 可查看、添加、删除记忆，询问或纠正记忆，并重新生成摘要。记忆更新提示也可点击进入。
- 默认群记忆和自动回顾保存到 `memory/groups/<群ID>/`，只在本群会话注入，不自动混入其他群或私聊。
- 同一群由一位记忆管理成员统一回顾；回顾调用 PI 配置的模型，并计入本群用量。
- 群聊删除成功后后台归档记忆；保存失败时保留原群和记忆。升级前已保存在个人或团队记忆中的旧条目不会猜测归属或自动移动。

## 消息时间与回复耗时

- 入口：直接打开私聊或群聊，无须另开设置。
- 用户消息下方显示发送时间，Bot 名称旁显示时间及有实际记录的回复耗时；悬停时间可查看完整日期，使用本机时区。
- 旧消息没有耗时记录时不补造数值。不增加周期计时器，保留已有流式正文增量更新机制。

## 通用交互卡片

- 入口：在支持原生工具调用的 Bot 私聊中，向 Bot 描述要展示的卡片。
- 例如：“请用 show_view 交互卡片给我两个方案，让我选择后再继续。”或“请用表格卡片展示检查结果。”
- 支持文本、指标、表格、进度、单选/多选、确认和短表单；可通过 stack 组合展示。
- 提交后答案返回原 Bot，支持草稿保留、重复点击保护、派发失败重试、普通重启恢复与历史归档。新消息会替代尚未回答的交互卡片。
- 和上游一致，交互卡片目前限私聊。仅规划模式的管理员不能直接执行该工具，可使用执行成员，或在 Bot 设置中选择原生 Agent 模式；模型是否调用工具由模型决定。
- 从备份恢复时暂停待回答卡片及未完成派发，避免意外重复执行。蓝图与标题限制为 8 KB，按纯文本和固定组件渲染，不执行模型给出的 HTML/脚本；密码和密钥仍使用专门的密钥入口。

## 侧栏修复

- 修复原生侧栏插件停用后，PI Bot 固定留在第二格、左侧出现空位的问题。
- 左边插件停用后自动向左补位；重新启用后自动避让，两个入口不重叠。
- 停用 PI Bot 时只释放自己的入口和占位归属，其他插件仍然可用；最后一个入口卸载后清理整行占位。

## 安装

在 PI Desktop 插件管理页导入 `local.pi-bot-0.3.82.piplug`，然后重载插件或重启 PI Desktop。插件 ID 仍为 `local.pi-bot`，可从 0.3.81 直接更新。

`PI-bot-0.3.82.piplug` 是内容一致的旧更新器兼容附件；上传插件中心时使用 `local.pi-bot-0.3.82.piplug`。

- 110 项回归测试，覆盖群记忆隔离、当前成员权限、归档、卡片校验、回答重试、备份恢复、消息元数据和状态增量同步。
