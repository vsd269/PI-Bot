# PI Bot 0.3.104

修复回复状态重复，以及私聊执行时右下角没有停止按钮的问题。

- 同一任务不再同时显示消息下方的“执行中”和独立的“正在回复”；思考、工具执行、等待批准等运行状态统一显示一份。
- 保留任务结束、失败、中断等历史结果，不隐藏错误。
- 私聊中有排队、启动、执行、等待批准或等待队友交回的任务时，右下角显示停止按钮，空输入框也可直接点击。
- 点击后立即显示“正在停止”，暂时禁用重复点击并隐藏语音通话按钮；实际调用任务中断接口。
- 停止范围固定为点击时所在 Bot 的私聊任务；中途切换聊天不会误停其他 Bot，也不影响同一 Bot 在群里的工作。
- 停止失败时提示重试，恢复可操作状态；保留已有回复及未发送草稿。已完成的文件修改不会撤销。
- 延续 0.3.102–0.3.103 的消息操作图标调整和表情即时反馈修复。

## 验证范围

使用隔离数据验证运行状态筛选、原生中断参数、取消排队任务和持久化；使用模拟宿主的浏览器界面验证流式更新、工具与审批状态切换、停止失败重试、切换聊天、群聊以及历史结果保留。

以上验证不等于真实 PI Desktop 中对模型或工具执行的端到端验收；中断最终完成由宿主返回执行结果确认。

## 安装

使用 `local.pi-bot-0.3.104.piplug`，安装后重载 PI Bot 插件或重启 PI Desktop。桌面保留旧版本包，本轮未发布 GitHub。
