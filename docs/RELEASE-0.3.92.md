# PI Bot 0.3.92

本版修复窗口布局交互，并包含 0.3.91 的任务分派和任务追踪更新。插件 ID 仍为 `local.pi-bot`。

- 左侧拖动条归入实际布局，随宽度移动；连续拖动和折叠不再丢失拖动目标。
- 右侧会话详情提供可聚焦的宽度手柄，支持拖动、左右方向键、Home／End 和宽度记忆。左右栏宽度均保存在本机界面偏好中。
- 聊天预留空间和自动折叠依据右栏实际宽度计算。详情栏开合保留 300 ms 动画；系统设置“减少动态效果”时直接切换。
- PI 原生工作区收起时，插件覆盖层跟随实际退出动画；保留原生宽度手柄的命中区域。
- 顶栏使用独立的 Electron 拖窗区域，位于聊天顶栏空白处，避开窗口控制按钮；隐藏／卸载插件时移除。

## 验证边界

新增测试在无头 Chromium 中挂载完整 PI Bot 渲染器，实际模拟鼠标拖动，检查连续左右调整、持久偏好、快速开合、动画中间帧、原生手柄不被遮挡、窄窗口和减少动态效果偏好。另检查独立拖窗区域的实际位置、CSS 和卸载清理。

原生工作区使用隔离的宿主 DOM 和动画夹具；未修改用户已安装插件或 PI Desktop 程序文件。无头浏览器不能验证 Windows 窗口管理器的实际窗口移动，顶栏拖窗仍需安装后在 PI Desktop 中验收。没有进行真实模型联调。

代码回归：326 项，325 通过、1 跳过、0 失败；214 个脚本语法及版本一致性检查通过。新增布局界面检查和原有 0.2.1／0.2.4 迁移界面检查通过，无页面脚本错误。

安装新包后请重载 PI Bot 插件或重启 PI Desktop。先前版本安装包保留。
