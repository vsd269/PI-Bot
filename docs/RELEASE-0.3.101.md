# PI Bot 0.3.101

本版补全消息阅读、文字操作和实时执行反馈，并修复右侧详情的界面细节。

- **图片消息**：发送后立即显示缩略图，历史图片自动读取，点击可放大。群聊也可使用；加载失败就地重试。图片读取仍校验对应 Bot／群和消息附件，历史大图预览上限与现有 20 MiB 图片限制一致。
- **新消息**：在未读回复开始处显示横向分隔线，流式更新同一条回复不会反复计数；切换回来可定位未读处，读到后自动淡出。
- **工具记录**：步骤默认折叠，展开显示易读输出、错误和退出码；保留原始记录入口。此处只整理显示，不改变工具执行权限或结果。
- **文字操作**：选择消息文字后出现独立引用按钮。右键菜单按撤销、重做／剪切、复制、粘贴、粘贴并匹配样式／全选分组，保留快捷键和相应禁用状态。菜单跟随 PI Desktop 当前中英文；设置为跟随系统时使用宿主解析的语言。插件内独立实现菜单，不依赖宿主未公开的原生菜单接口。
- **实时状态**：小头像配合简洁状态文字，区分排队、思考、工具执行、等待批准和等待队友；依据实际任务更新，完成或切换聊天后清除。
- **详情与按钮**：修复头像底板偏位和编辑笔常驻；触屏保留可发现的编辑入口。齿轮设置不再重复显示头像名字，保留分享／设置／关闭；放大消息旁三个操作按钮。

## 验证范围

使用隔离模拟数据进行浏览器交互检查：中英文和系统语言、只读菜单、部分复制、剪切、纯文本粘贴、撤销／重做、键盘导航、工具记录、实际状态映射、未读定位与历史图片。另执行项目测试、语法检查及包完整性校验。模拟检查不等于真实 PI Desktop 上的全面运行验收。

## 安装

安装包：`local.pi-bot-0.3.101.piplug`。保留旧版本；更新后请重载 PI Bot 插件或重启 PI Desktop。本次 GitHub 正式发布合并 0.3.94～0.3.101，完整变化见 [合并说明](GITHUB-RELEASE-0.3.101.md)。
