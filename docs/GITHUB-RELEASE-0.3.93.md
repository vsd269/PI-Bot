# PI Bot 0.3.93 · 任务分派修复、执行追踪与应用连接

本次从 GitHub 0.3.90 升级至 0.3.93，合并发布 0.3.91、0.3.92、0.3.93 三次更新。

## 修复社区报告：管理员计划异常（0.3.91）

修复 [Issue #1](https://github.com/vsd269/PI-Bot/issues/1)。感谢 [@royrao2007](https://github.com/royrao2007) 提供详细复现、问题分析与改进建议。

- 管理员输出的 JSON 字符串含未转义换行等控制字符时，先尝试只修正字符串内的控制字符，保留正常转义内容。
- 重复派发、未知成员、成员重名、误派给管理员分别显示具体原因；不猜测成员，也不执行半份计划。
- 计划验证失败时，最多请求同一管理员纠正一次；群聊初次规划、管理员私聊和群聊结果回收均覆盖。
- 纠正仍失败时保留原本可读回复和诊断，不再用一句笼统错误覆盖全部回复。网络失败或提交状态不确定时，不借格式纠正自动重发任务。
- 完整计划验证、状态保存及停止／成员／隐私状态检查通过后才执行；纠正不能添加新的团队操作。

**For the reporter:** Fixed #1. Thanks @royrao2007 for the detailed reproductions and suggestions. Literal control characters inside JSON strings are repaired conservatively; recipient diagnostics are now specific; invalid plans get at most one corrective pass. If correction fails, the readable administrator reply is retained and no partial plan is dispatched. Regression coverage includes group planning, private administrator chat and group-result collection. Real PI Desktop/model acceptance testing is still needed.

## 执行追踪与后台优化（0.3.91）

- **定时任务执行记录**：为每轮执行保存稳定编号和关联任务，区分执行、等待、完成、失败、中断和跳过。上一轮未结束时跳过下一轮，避免重叠运行。
- **本地文件条件等待**：工作目录内指定文件出现或大小／修改时间变化后执行一次任务，支持到期和取消。等待本身不调用模型，触发后的执行仍可能产生模型费用。
- **工具重复失败提示与工作摘要**：在“待处理”中查看重复错误、工具使用次数和已保存结果；没有独立核对凭据时明确标注。
- **自动记忆原话来源**：自动记忆修改需匹配新的用户原话；可在记忆面板查看来源并定位聊天。此为保守来源筛选，不代表事实认证。
- **团队配置模板**：预览、导出和导入角色分工与群结构；不携带聊天、记忆、密钥、账号授权及本地目录。周期任务导入后暂停，技能需重新导入和分配，默认排除私密 Bot。
- **减少空闲开销**：无变化时不再反复保存整个团队状态，空闲检查降低频率；任务准入、停止和恢复仍确认保存成功。
- 加强进程锁身份核对及交接来源标记，降低旧进程编号误判，并区分队友报告与用户真实授权。

## 侧栏与窗口交互（0.3.92）

- 修复左侧宽度拖动条位置，支持反复调整、键盘调整和宽度记忆。
- 右侧会话详情支持拖动缩放、键盘调整与宽度记忆，聊天区域按实际宽度让位。
- 恢复右侧栏展开／收起过渡，快速开合保留最终状态；遵守系统减少动态效果偏好。
- 调整顶栏拖窗区域，避开窗口控制按钮及侧栏控件；保留原生工作区宽度拖动区域。
- 保留窄窗口自动折叠及头像栏行为。

## 应用连接（0.3.93）

- 新增应用图标、分类分组、双列卡片、搜索、分页和已连接入口，支持浅色、深色及窄窗口。
- 每位用户填写自己的 **Composio 项目 API Key**，通过官方授权页面连接账号，再分配给多个指定 Bot 或全部 Bot。
- 应用目录及账号从各自项目读取；未配置时的预览卡片不代表已经连接，也不保证每个项目拥有完全相同的目录。
- 项目密钥、会话和分配保存在当前 Windows 用户的加密密钥库中，不进入普通团队备份或模型上下文。此版本不提供公共授权服务器。
- 应用工具按账号、工具包版本和 Bot 分配检查；修改类操作沿用 PI Desktop 原生审批，不自动重试外部写操作。
- 保留 GitHub PAT 与本地／远程 MCP 连接方式；补全页面操作图标及图片加载失败时的回退图标。

Composio 及第三方服务的额度、权限、费用和地区可用性由用户自己的账号决定；部分应用需先在自己的项目中启用 Auth Config。真实第三方授权未逐家联调。

## 功能入口

| 功能 | 入口 |
| --- | --- |
| 应用连接与账号分配 | 左下角“连接应用” → Composio 卡片“配置” → 连接应用 → 分配 Bot |
| 定时任务执行记录、文件条件等待 | 插件设置 → 定时任务 |
| 工作摘要、工具重复失败提示 | 插件设置 → 待处理 |
| 团队配置模板 | 设置 → 关于 PI Bot → PI 扩展 → 备份与恢复 |
| 记忆原话 | Bot／群聊 → 记忆面板 |
| 侧栏宽度 | 拖动左右侧栏边缘，或聚焦手柄后使用方向键 |

## 下载与更新

下载 `local.pi-bot-0.3.93.piplug`，在 PI Desktop 中安装更新。`PI-bot-0.3.93.piplug` 为兼容旧更新入口的同内容文件，只需安装一个。另提供源码压缩包及 `SHA256SUMS.txt`。

插件 ID 保持 `local.pi-bot`。建议更新前导出个人备份。更新后请重载 PI Bot 插件或重启 PI Desktop。
