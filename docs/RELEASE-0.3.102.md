# PI Bot 0.3.102

本版仅调整消息旁的表情、回复、更多三个操作按钮。

- 保留 28px 点击区域，将内部 SVG 从 16px 调整为 20px，并按图案重新设置留白，实际图案宽度约为 13～15px。
- 悬停背景调整为圆形，保留显示时机、表情菜单、回复引用、更多菜单和时间位置。
- 调整仅作用于消息操作按钮，不改变其他图标和窗口按钮。

## 验证

使用隔离模拟宿主检查真实图案尺寸、点击功能、浅色／深色、私聊／群聊和窄窗口边界。浏览器模拟检查不等于实际 PI Desktop 原生环境验收。

## 安装

安装包：`local.pi-bot-0.3.102.piplug`。保留旧版本安装包，本轮不自动发布 GitHub。更新后请重载 PI Bot 插件或重启 PI Desktop。
