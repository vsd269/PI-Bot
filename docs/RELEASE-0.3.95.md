# PI Bot 0.3.95

本版集中调整界面细节，并包含 0.3.94 的应用连接错误提示与侧栏分隔条修复。

- 顶部搜索和新建按钮使用 36px 圆形，中间 Bot 按钮使用 40px 高胶囊，两者中心在同一条 52px 顶栏上；右侧为向右小尖角。
- 左下角头像和连接应用按钮为 36px，间隔 8px。默认展示 Gmail、Slack、Notion，连接后优先展示实际已连接应用。默认图标只表示入口示意，不代表已获得授权。
- **设置 → 通用 → 我的头像**：上传 PNG、JPEG、WebP、GIF 或恢复 PI 默认头像。图片转换为小尺寸静态头像保存，GIF 不保留动画；保存失败恢复之前头像。
- 详情栏圆形工具按钮为 34px、间隔 10px；模型、权限、目录、说明和管理入口统一为圆角卡片，保留现有功能。
- 消息旁的表情、回复、更多按钮紧随气泡；同一行显示时间。时间使用现有已授权打包的 Geist 字体，11px、常规字重、等宽数字。私聊与群聊采用相同规则，完整日期可悬停查看。回复耗时继续显示在消息名称旁。
- 顶栏使用实际分离的矩形拖动区域避开可点击按钮。窗口控制保留 PI Desktop 自己的最小化、最大化/还原和关闭处理，仅在插件启用时调整外观；停用后清除作用域样式。
- 窄窗口和平铺消息布局为操作按钮和时间保留独立位置，避免显示到窗口外。两侧栏拖动、宽度记忆、展开收起动画和减少动态效果设置继续保留。

## 验证范围

使用隔离浏览器夹具检查按钮尺寸、间距、时间字体、实际点击、深浅色、窄窗口、侧栏拖动和动画、宿主控制处理保留及样式清理。测试包含头像上传、持久化、恢复默认、无效格式拒绝和保存失败恢复，以及私聊、群聊时间去重。运行完整单元回归、语法/版本检查、应用页面回归、插件包内容验证和本地市场预检。

这些是本地代码及模拟宿主界面验证，不等同于已在用户实际运行的 PI Desktop 中完成重载验收。默认服务图标的网络可用性仍取决于本机网络；错误时保留安全图标回退。
