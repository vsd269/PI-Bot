# PI Bot 0.3.110

基于 0.3.109 修复“应用”窗口长时间停在“正在读取应用设置”、主体列表空白的问题。继续保留 0.3.109 的启动自动检查和原有 Bot 应用授权。

## 原因与修复

旧流程在开始加载目录前等待账号检查和分类列表；获取主目录后，又等待首页分类分组全部返回才绘制列表。任一分类请求缓慢都会拖住整页。应用请求原先还排在持续会话刷新之后，在繁忙聊天中可能进一步延迟。

- 打开窗口立即呈现已有连接，以及之前读取的目录或标注为“内置应用预览”的本地列表，不再只显示一行加载文字。
- 账号、分类与主目录独立读取。主目录返回即显示；分类分组逐个补充，不等待其他分组全部返回。
- 已连接账号即使不在当前目录第一页，也能显示在首页“已连接”区域。
- 应用读取与会话同步使用同一级队列，避免被连续聊天分块一直挤到后面；停止、发送和回答等紧急操作仍保持更高优先级。
- 界面读取增加 15 秒等待上限。设置、账号或主目录读取失败／超时时保留可用列表，并给出可刷新重试的提示；可选分类失败不阻塞主目录。
- 刷新和加载更多失败后保留已有内容，分页可重试；缓存仅用于展示，不代替账号与权限校验。
- 设置尚未读取成功时暂不允许修改账号与 Bot 分配，防止把未加载的授权当作空配置保存。
- 搜索、切换账号页、关闭或重新打开窗口后，晚到的目录／分类结果不会覆盖当前页面；关闭窗口时清理界面等待计时器并忽略晚到结果。

内置应用预览不是服务端成功响应，也不代表账号已连接。实际授权与工具执行仍由保存的配置、Bot 分配及服务端账号状态决定。本次不自动重新授权，也不重试任何写入工具。

## 安装

在 PI Desktop 的插件页导入 `local.pi-bot-0.3.110.piplug`，保留 `local.pi-bot` 的原有插件数据。重载插件或重启软件后生效。

源码包用于继续开发，不用于插件页导入。无需重新配置已有 Bot 或应用密钥；第三方服务不可用、密钥失效或账号授权过期时仍需按具体错误处理。

## 验证

新增慢请求界面测试，先在 0.3.109 基线上复现分类请求不返回导致主目录不显示，再验证新版修复。覆盖分类卡住、分组卡住、账号检查缓慢、设置读取缓慢、目录超时、刷新恢复，以及晚到结果不覆盖搜索／账号页。

验证使用隔离配置和模拟服务；未访问真实 Composio 项目，未调用真实模型或外部写入工具，也未修改当前已安装插件和用户数据。
