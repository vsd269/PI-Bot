# PI Bot 0.3.91

本版修复管理员计划格式导致的整轮任务失败，并补充任务追踪与配置复用能力。沿用原有执行和持久准入层；未增加每次普通聊天都必须经过的审核模型回合。

## 修复 GitHub #1

感谢 [@royrao2007](https://github.com/royrao2007) 在 [Issue #1](https://github.com/vsd269/PI-Bot/issues/1) 中提供详细复现与改进建议。本节修复随 0.3.93 合并发布。

管理员把同一 Bot 分派两次，或在 JSON 字符串中输出未转义换行时，不再直接丢掉整个回复。

- 只自动修正 JSON 字符串内未转义的控制字符，不猜测成员，不执行半份计划。
- 计划校验失败最多请同一管理员纠正一次。未知提交状态、网络失败和工具失败不因此自动重发。
- 重复、未知、重名和管理员成员分别给出原因。最终失败仍保留可读回复和脱敏后的原计划，供核对。
- 覆盖群聊初次规划、管理员私聊、群结果回收。纠正后重新检查停止、成员与隐私状态，不能添加新的团队操作。

## 功能入口

| 能力 | 入口与行为 |
| --- | --- |
| 定时任务执行记录 | 设置 → 定时任务 → 最近执行记录。区分排队、执行、等待用户／审批／队友、回合结束、失败、需要核对和跳过。上一轮未结束时跳过本次到期，不自动堆积。 |
| 文件条件等待 | 设置 → 定时任务 → 文件条件等待 → 新建文件等待。当前先支持执行 Bot；文件出现，或大小／修改时间变化后领取一次任务。可取消和设置到期时间。 |
| 工具重复失败提示 | 设置 → 待处理 → 运行异常。同任务内相同工具、参数和错误连续 5 次时提示；可打开原生会话或手动停止对应任务。 |
| 工作摘要 | 设置 → 待处理 → 已完成待查看／运行异常 → 工作摘要。展示工具次数、失败计数、已保存结果以及记录截断和未核对信息。 |
| 记忆原话 | Bot／群聊 → 记忆面板。自动复盘新增、修改或删除记忆需要匹配新用户消息中的原话，条目可查看原话并定位聊天；旧条目不补造来源。 |
| 团队配置模板 | 设置 → 关于 PI Bot → PI 扩展 → 备份与恢复。导出前检查配置；导入必须预览并确认，同名自动加序号，保存失败撤回本次新建对象。 |

后台活跃观察仍使用原有 500ms 默认间隔，空闲检查改为 5 秒；无可观察变化时跳过整队状态保存。定时唤醒按到期时间安排，并保留最长一分钟的休眠／时钟变化核对。准入、停止和恢复等关键保存没有改成忽略错误的后台写入。

## 边界

- 本地定时与文件等待需要 PI Desktop 持续运行、插件启用、原工作区可用；关闭时不检查。文件等待不轮询模型，触发后的任务执行仍可能产生费用。
- 文件条件限工作目录内的普通本地文件，拒绝网络路径、目录联接、符号链接和目录外路径；不支持网页、进程或邮箱事件。文件“变化”依据文件元数据，不承诺检测被人为还原全部元数据的内容改写。
- 工具保护先提示、提供手动停止，不新增固定群聊交接总次数限制，不声称能拦截宿主内部每一次工具调用。缺失工具标识或未结束的事件不会被强算为重复失败。
- 记忆校验是保守来源筛选，可能漏记；原话匹配不证明模型对其含义的解释正确，也不是覆盖所有语言或引用形式的事实认证。用户手动添加／编辑记忆保持原有行为。
- 工作摘要使用已有证据，不扫描全盘、不建立影子 Git。没有文件变更凭据时显示“未独立核对”。回合结束不等于外部动作已成功或成果已验收。
- 模板只携带角色说明、群结构、系统头像形状／颜色引用、技能名称参考和暂停的周期任务。不带聊天、记忆、图片头像、密钥、账户、授权和本地目录；默认不导出私密 Bot。技能需自行导入和分配；工作目录需重设。提示词中的个人资料仍需用户在预览中检查。
- 进程锁增加开始时间核对；查询失败、无权限或异常回收辅助锁时保守保留，不按文件年龄强删。此时仍可能需要人工关闭重复实例并检查锁文件。
- 交接报告具有来源和任务编号，但提示词边界不是系统级隔离；文件、命令和外部应用审批继续由 PI Desktop 控制。

## 安装与验证

新包保持插件 ID `local.pi-bot`，保留已有配置。安装后重载插件或重启 PI Desktop。旧版本自动化仅有派发记录时显示“结果未知”；不会编造历史完成状态。个人备份恢复会取消待触发的文件等待，不自动重放。

本轮使用临时目录和模拟宿主运行代码回归，并通过真实渲染器的无头界面检查；没有使用用户真实聊天数据或真实模型进行联调。系统断电、长时间运行及多机器真实宿主行为仍需安装后验收。

- 代码回归：326 项，325 通过、1 跳过、0 失败；212 个脚本语法检查通过，版本一致。
- 新功能界面及原有待处理页面：两组无头界面检查通过，没有页面脚本错误。
- 合成数据观察比较：约 478 KB 团队状态、连续 100 次无变化的活跃观察，旧版调用保存 100 次，新版 0 次；本机该段耗时约 232 ms / 0.9 ms。仅比较基线／新版 Team 与共用辅助模块的模拟检查开销，不代表真实模型首字、整体任务或耗电测量。
