# PI Bot 0.3.103

修复消息表情添加、移除反应慢的问题，包含 0.3.102 的消息操作图标调整。

- 点击表情后立即显示，再次点击消息下方同一个表情立即移除；选择另一个表情立即替换。
- 保存继续在后台完成，不再用整个会话快照覆盖当前界面。
- 表情变化只更新消息下的小标记，不重建整份聊天记录，保留原来的消息内容、选区和已展开的工具记录。
- 同一消息连续点击时，保存按顺序进行并合并中间选择；旧刷新和旧保存结果不会覆盖较新的选择。
- 私聊、群聊、用户消息、智能体回复及任务结果分别处理；切换聊天后保留尚在保存的选择。
- 保存失败时恢复最近保存成功的表情，并提示重试。服务端写入失败会回滚表情字段，保留同时到达的聊天内容。
- 保留上一版放大的表情、回复和更多图标及 28px 点击区域。

## 验证范围

使用隔离数据和模拟宿主验证延迟保存、连续添加／移除、切换表情、旧刷新、跨会话切换、保存失败恢复、并发聊天和磁盘持久化。浏览器模拟检查不等于真实 PI Desktop 原生环境验收。

## 安装

安装 `local.pi-bot-0.3.103.piplug` 后重载 PI Bot 或重启 PI Desktop。保留桌面旧版本安装包，本轮不自动发布 GitHub。
