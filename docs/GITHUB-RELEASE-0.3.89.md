# PI Bot 0.3.89 · 执行可靠性、工作经验与私密 Bot

本次合并发布 0.3.87～0.3.89 的三批改动，可从 0.3.86 直接升级。

## 0.3.87：任务派发更可靠

- 带请求编号的执行者任务，先保存任务和接收确认，再启动执行；重复请求不会再创建一份相同任务。
- 重启后核对派发与任务记录；状态不明时保留待核对，不悄悄重新执行。
- 恢复中心增加最近的执行状态记录，帮助区分排队、执行中、中断和结果交回。
- 保留原有私聊、群聊流式呈现，不额外增加模型规划或审核回合。

**入口：** 设置 → 关于 → PI 扩展 → 任务恢复中心 → 执行记录。

## 0.3.88：工作经验、群聊停止与文档工具

- 群详情新增“全部停止”，请求中止本群规划和成员任务，并阻止迟到结果继续派发。
- Bot 可从已完成任务中提出 Skill 或项目 AGENTS.md 建议；先预览，再由用户确认保存。
- 通用设置增加低频自动复盘，默认关闭；开启后会额外调用配置的模型。
- 左侧栏支持拖动宽度、折叠为头像栏；优化窄窗口下的左右栏收起顺序。
- 接入轻量 Office 工具：Word 段落/表格读取与定点编辑，PPT 清单/布局检查和页面操作，Excel 内容、公式及缓存值读取。

**入口：** 点击群聊标题 → 群详情 → 全部停止；Bot 私聊 → 复盘经验；通用设置 → 工作经验 / Office 文档。

Office 工具需要独立 Node.js 20+；不包含完整 Office 排版引擎、旧 .doc/.ppt/.xls 编辑或 Excel 公式重算环境。

## 0.3.89：新增私密 Bot

- 普通 Bot 可开启私密模式；需独立工作目录，不能加入群聊，主 Bot 不支持开启。
- 限制其他 Bot 通过插件读取其资料、聊天、记忆和任务，阻止自动派发与共享写入。
- 需要分享的内容由用户手动转交；经验 Skill 提案在确认前提示共享范围。
- 增加目录异常、删除归档、备份校验及保存失败回滚保护。

**入口：** 选择普通 Bot → 点击聊天顶部的 Bot 名称 → 编辑会话 → 隐私 → 私密 Bot。该开关不在全局“通用”页面。

私密模式属于插件层保护，不是加密保险箱或系统级沙箱；PI Desktop 原生文件、命令、MCP、子会话的全面隔离尚未验证。模型仍使用用户配置的服务，开启前已共享的内容不会自动撤回。

## 验证与升级

- 本地语法检查：195 个脚本通过。
- 本地回归：238 项，237 通过、0 失败、1 项因 Windows 符号链接权限跳过。
- 界面自动化：私密 Bot 7 个场景，以及相关既有界面 23 个场景通过。
- 插件包内容、校验和及已知市场提交模式预检通过；不等于完整平台审计。
- 自动化使用测试数据和模拟宿主；真实模型、原生工具、语音和跨平台效果仍需实际环境验收。

升级前建议导出备份。下载 **local.pi-bot-0.3.89.piplug**，通过 PI Desktop 插件管理安装后重载插件或重启客户端。无需同时安装 0.3.87 / 0.3.88。停止任务不撤销已完成的外部修改。

本项目为 DS Bot 的独立 PI Desktop 适配版，保留上游与随包依赖的来源、署名和许可证。本次发布不修改 PI Desktop 客户端二进制。
