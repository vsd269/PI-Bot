# PI Bot 0.3.86

本版继续将适合 PI Desktop 的功能迁入现有 PI Bot。上游项目现名为 DS Bot；其 GitHub 仓库 URL 和历史来源记录保持不变。本版不包含独立浏览器迁移。

## 新增

- **共享头像库**：在 Bot 头像编辑器的“共享库”页查看、分页、复用及删除上传头像。每页 12 个，最多 300 个；正在被 Bot 使用的头像不可删除。头像原图与预览分开保存；Bot 配置只放入不超过 160 像素的高质量版本，避免重复保存大图。头像库纳入完整备份与恢复。
- **`/side` 侧问别名**：在 Bot 私聊中输入 `/side 问题`，行为与 `/btw 问题` 相同。侧问仍使用该 Bot 的模型并计入正常用量。
- **侧问记录清理**：已回答、已取消或失败的侧问卡片可直接删除；回答中的侧问需先取消或等其结束。
- **Bot 队列提示**：被其他 Bot 派发、仍处于队列中的任务会显示“尚未读取”及待办数量。PI 队列状态保持原样；Bot 开始处理后提示随队列状态更新。
- **`message_bot` 请求去重**：调用方用稳定的 `request_id` 标识同一个派发请求。相同编号和内容的并发调用或重试只入队一次；同一编号若改用不同内容会报错。插件重启时未完成的请求标记为中断，不自动重试，避免重复派发。
- **上游名称**：当前项目文字使用 DS Bot；实际链接仍指向既有 GitHub 仓库。历史许可证与来源记录保留。

## 兼容与限制

- 头像库在旧数据中不存在时按空库启动；已有 Bot 头像不迁移、不覆盖。新备份加入独立头像库数据，旧备份可照常恢复为空库。
- `message_bot` 的 `request_id` 必须在调用方重试同一逻辑请求时复用；新的任务使用新的编号。为了避免不确定请求状态造成重复派发，崩溃或重启后的请求不会自动重放。
- 上游仓库地址目前仍使用历史的 `DeepSeek-Bot` URL 路径，项目展示名已更新为 DS Bot；没有更改本项目 `vsd269/PI-Bot` 地址。

## 安装

安装 `local.pi-bot-0.3.86.piplug`，然后重载插件或重启 PI Desktop。插件 ID、权限声明和原有数据目录不变，不携带作者的 Bot、聊天或凭据。`PI-bot-0.3.86.piplug` 是为旧版更新检测保留的同内容兼容附件，只需安装一个。
