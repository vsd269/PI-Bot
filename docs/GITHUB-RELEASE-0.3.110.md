# PI Bot 0.3.110 · 消息同步、任务停止与应用连接修复

本次从 GitHub 已发布的 **0.3.107** 升级到 **0.3.110**，合并 **0.3.108、0.3.109、0.3.110** 三次更新。重点解决长任务回复过期、实时输出与停止响应、原生提问卡，以及应用连接恢复和页面长时间空白的问题。

## 0.3.108：消息同步、任务停止与交互体验

### 回复与实时状态

- 修复持续读取的任务仍出现 `Request expired.`：请求按最近读取时间续期，完成结果可以重复读取，并在读取后释放；请求失效时提示刷新，不自动重跑已提交的任务。
- 大状态响应支持协商式 gzip 压缩，减少长聊天、头像等内容通过桥接传输的等待。
- 管理员规划过程支持流式展示，只显示可读的回复内容；规划、排队和私聊处理时持续显示工作状态。
- 根据会话和回合身份匹配输出，过滤重复子代理消息；缺少回合标识时，仅在可以唯一匹配的情况下接收，减少内容串到其他会话的问题。

### 停止与原生提问

- 停止、群聊全部停止、回答问题、发送消息和已读确认优先处理。
- 群停止先阻止旧任务继续分派，再并行发出原生中断和保存；同时处理群成员及管理员规划。
- 重复停止已结束任务不再报 `No active task to interrupt.`；补发停止时核对原来的回合身份，避免误停新的任务。
- 原生提问卡可直接在 PI Bot 内显示和回答，支持多题、单选、多选、自定义回答、跳过单题及拒绝整组。
- 未回答的原生提问可以恢复显示；多题回答收齐后继续原来的工具请求，不额外启动一轮任务。

### 群聊与未读

- `@` 候选加入群管理员，并显示头像与名称；`@管理员` 进入规划流程，保留普通 `@`、`@all` 及串行／并行执行。
- 群内系统提示使用该群管理员的名称、头像和颜色，兼容历史提示记录。
- 群回复不再误标成员私聊未读；已读确认避免旧快照重新点亮圆点，同时保留新消息和手动标未读。
- 折叠侧栏的未读圆点固定在头像右下角；图片预览的放大按钮改为四角展开图标。

## 0.3.109：应用连接自动恢复

- 启动后自动读取已保存的加密 Composio 项目配置，在后台检查已有账号并同步侧栏；无需先打开“连接应用”窗口。
- 保留原有 Bot 分配；后台检查不阻塞聊天，也不在启动时加载完整应用目录。
- 启动检查与应用窗口共用进行中的请求，成功结果可复用一分钟；需要时仍可手动强制刷新。
- 正常每五分钟更新账号状态；临时网络错误采用逐步延长的重试间隔，最长五分钟，失败时保留已有配置。
- Bot 上下文可获得已分配的应用账号和工具发现入口，继续校验 Bot 权限及账号状态，不向聊天暴露密钥。
- 更换或清除配置后，旧请求与缓存不会覆盖新配置；卸载插件时停止后台检查。
- 自动恢复仅检查连接状态，不自动重新授权、不自动执行应用工具，也不重试外部写入操作。

## 0.3.110：应用页面不再长时间空白

- 账号、分类、主目录独立加载；主目录返回即可显示，首页分类逐个补充，不再等待所有请求完成。
- 打开窗口先显示已有连接、缓存目录或明确标注的“内置应用预览”，在线内容在后台更新。
- 已连接账号即使不在目录第一页，也能在“已连接”区域直接管理。
- 应用读取与会话同步使用同一级队列，避免持续聊天刷新拖住应用页面；停止、发送和回答仍享有更高优先级。
- 界面读取增加十五秒等待上限；超时或失败时保留可用内容，提供刷新重试提示，可选分类失败不拖住整页。
- 刷新、加载更多失败后保留已有列表，分页可以重试。
- 搜索、切换账号页、查看详情或关闭重开后，晚到的目录和分类结果不会覆盖当前页面；关闭时清理等待计时器。
- 设置未成功读取时暂不允许修改账号和 Bot 分配，防止把尚未加载的授权当作空配置保存。

内置应用预览和目录缓存只用于展示，不代表在线读取成功或账号已经授权，也不代替实际权限校验。

## 安装与升级

1. 下载 **`local.pi-bot-0.3.110.piplug`**，在 PI Desktop 插件页面导入。
2. 保持原插件 ID `local.pi-bot`，直接更新，**不要先删除插件数据**。
3. 更新后重载 PI Bot 插件或重启 PI Desktop，在“关于”中确认版本为 **0.3.110**。

现有 Bot、聊天记录、主题、头像、应用配置和分配沿用原数据。跨电脑迁移个人数据需使用插件备份／恢复；密钥使用原有的加密迁移导出／导入功能。源码 ZIP 用于开发，不用于插件页面导入。

停止速度仍受 PI Desktop、网络和工具本身影响，停止不会撤销已经完成的文件修改或外部操作。第三方服务不可用、密钥失效或授权过期时，仍需按具体错误处理。
