# PI Bot 0.3.84

## 附件规则

对照用户本地 DeepSeek Bot 0.2.0 源码，以及该版本固定使用的 DSH 0.2.1-rc.2 附件和上传实现：

- 普通文件不再统一限制为单文件 20 MB，不设置共用的 8 个附件上限。文件长度使用安全整数校验，不使用 32 位位运算计数。
- 支持的聊天图片单张最多 20 MiB（20 × 1024 × 1024 字节）。每条消息最多 20 张图片，图片合计最多 200 MiB；普通文件不占用这 20 张图片的名额。
- 图片的原始文件字节保持不变，不在本插件中额外压缩或降质。模型或 PI 原生会话可能有自己的图片处理和输入限制。
- 普通文件使用浏览器分片读取、后端顺序写盘和会话附件分块复制，不把整份文件或完整 Base64 聚集到内存。
- 上传失败、取消、过期或停用后清理未完成文件；正常完成的附件仍保留供历史消息和群聊转交使用。

## 验证与边界

覆盖超过 20 MiB 的真实附件上传、完整字节校验和会话转交；3 GiB 文件声明不会被旧限制拒绝；20/21 张图片、20 MiB 单图、200 MiB 图片总量以及混合普通文件的边界检查。3 GiB 声明测试不等于已通过完整 3 GiB 的宿主上传实测。

PI 插件通信桥仍有单次消息大小和调用频率限制，因此分片上传大文件的速度取决于宿主桥。取消 20 MB 门槛不代表与 DeepSeek Bot 的原生直传具有相同速度。文件可附加不等于所选模型能够直接理解全部内容；尤其大视频可能只能读取文件属性，是否能分析画面取决于模型和视频处理工具。

## 升级与安装

本版包含此前本地交付的 0.3.83 全部修复，可从 GitHub 正式版 0.3.82 直接升级：

- 修复附件不在原生会话允许目录中而无法读取的问题，群聊转交给其他成员时使用接收成员的会话附件目录。
- 修复长消息全文读取失败和长中文请求超出通信桥单次大小限制的问题；展开后的长消息不会因后台刷新自动折叠。
- 输入框支持 Ctrl+V 粘贴剪贴板提供的 TXT、Word、图片等文件，支持多文件和仅附件发送；普通文本仍正常粘贴为可编辑文字。

安装 `local.pi-bot-0.3.84.piplug` 后重载插件或重启 PI Desktop。原有 Bot、群聊、能力及语音配置继续使用，无需新增插件权限。`PI-bot-0.3.84.piplug` 是供旧版更新检测使用的同内容兼容包，两者只需安装一个。下载文件可使用同一 Release 的 `SHA256SUMS.txt` 校验。

GitHub Release 与 PI Desktop 插件市场为两个独立发布渠道，插件市场需要单独提交。本版不包含自动覆盖运行中插件或静默安装。
