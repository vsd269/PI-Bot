# PI Bot 0.3.101 更新说明

本次合并发布 0.3.94～0.3.101 的改进，重点优化应用连接、图片与附件、语音交互、聊天阅读以及智能体详情面板。已安装 0.3.93 的用户可直接更新到本版。

## 一、应用连接更稳定，错误提示更清楚

- 修复连接应用后错误反复弹出、错误提示残留在聊天顶部的问题。应用连接的错误现在在应用页面内显示。
- 授权状态自动检查失败后暂停轮询，避免持续报错；完成授权后可点击“我已授权，检查连接”，也可手动刷新。
- 区分网络连接失败、请求超时、密钥无效、权限不足、限流和响应格式异常，便于判断问题。
- 读取连接失败时保留已有账号、项目配置与 Bot 分配。对可能产生外部修改的操作不自动重试，避免重复提交。
- 左下角连接入口优先展示已连接应用；未连接时的默认图标仅作入口示意，不代表已经获得授权。

## 二、新建智能体有更贴合职责的开场

- 新建 Bot 后立即显示开场问候和任务选项，无需等待模型返回。
- 本地开场会参考智能体名称、职责与说明，后台再使用该 Bot 所选模型生成更具体的问题和 3～4 个选项；生成失败保留本地开场。
- 支持点击选项、字母快捷键和自定义输入，保留多选问题的回答方式。
- 用户尚未回答或主动跳过的开场卡片，切换聊天、进入设置、进行其他工作或重新打开后仍会保留；已回答或主动关闭的卡片不会重新弹出。
- 用户开始聊天、回答问题、修改名称或删除 Bot 后，迟到的开场生成结果不会覆盖当前内容。
- 修复新建页面选择共享头像时报错的问题。

## 三、图片和附件发送、预览体验完善

- 修复群聊管理员与规划模式管理员私聊漏传附件的问题，图片和文件通过对应的 PI 原生会话传递。
- 添加图片时立即显示完整比例缩略图；文档、音频和视频显示类型、大小及添加状态。
- 上传失败可在附件卡片上重试，也可移除正在添加的文件；切换聊天时不再混入另一段对话的附件。
- 修复图片发送后只显示文件信息、不显示缩略图的问题。私聊、群聊和历史消息均支持图片预览，点击可放大；读取失败可就地重试。
- 修复管理员私聊中持续转圈的临时回复，执行过程原位更新，结束后保留最终回复。
- 加强附件任务提交前的保存检查；提交后如保存失败，会请求停止对应轮次。重启后对状态不确定的任务提示核对，避免自动重复执行。

## 四、聊天阅读与消息操作更顺手

- 优化回复正文、标题、列表、引用及代码块的字号和行距，让长回复更容易阅读。
- 私聊和群聊的消息操作旁显示发送时间，悬停可查看完整日期；保留回复耗时显示。
- 放大表情、回复和更多操作三个按钮，调整图标、圆角及间距，减少误点。
- 选中文字后出现独立“引用”按钮，可把片段带入输入框；也可仅复制选中的一小段。
- 新增完整文字右键菜单：撤销、重做、剪切、复制、粘贴、粘贴并匹配样式、全选，保留对应快捷键。
- 右键菜单跟随 PI Desktop 当前界面语言：中文显示中文，英文显示英文；跟随系统时使用宿主解析的语言。只读消息中不可用的编辑操作置灰。

## 五、新消息与工作进度更容易看见

- 在未读回复开始的位置显示“新消息”分隔线；离开对话后再回来，可定位未读内容。
- 同一条回复边生成边更新时不重复计算新消息；读到分隔线后自动淡出。
- 智能体工作时显示小头像和简洁状态文字，区分排队、准备、思考、回复、执行工具、等待批准和等待队友等状态。
- 群聊可区分不同成员的工作状态；任务结束或切换聊天后及时清理，减少过时提示。

## 六、工具记录从原始数据变成可读步骤

- 工具记录默认折叠，展开后按步骤显示工具名称、状态和简短摘要。
- 自动整理嵌套文本，区分正常输出、错误及退出码，减少成堆转义字符和重复内容。
- 保留“原始记录”入口，排查问题时仍可查看原始信息。
- 此项只优化展示，不改变工具权限、审批或执行结果。

## 七、表格回复支持搜索、复制和导出

- 表格使用独立圆角卡片，优化边框、背景、间距和长内容显示。
- 支持搜索内容、显示筛选行数、按列排序，以及悬停后的复制、CSV 下载和放大查看。
- 修复超过 100 行的数据被截断，以及表格紧接正文时无法正常识别的问题。
- 导出时处理可能被电子表格识别为公式的内容，减少误执行风险。

## 八、语音通话更紧凑，输入反馈更及时

- 语音对话改为紧凑通话浮条，聊天区域保持可见；可展开或收起文字记录。
- 保留暂停／恢复聆听、结束通话和语音设置入口。
- 使用受支持的实时转写服务时，录音过程中持续发送音频，停止后等待最终文字确认，减少整段录完才上传造成的等待。
- 其他语音服务沿用文件转写流程，不擅自更换用户选择的服务或模型；取消后迟到的结果不会再写入输入框。
- 调整语音按钮图案与悬停效果。实际转写速度仍取决于所用服务和网络。

## 九、右侧面板分类更清楚

- 右侧智能体面板分为“详情／资料库／电脑”，减少所有设置挤在同一页的问题。
- “资料库”集中展示智能体记忆、技能和工作文件夹，进入技能管理时默认定位当前 Bot。
- 浏览器、工作区和终端入口收纳到“电脑”页；移除聊天顶栏重复的工作区按钮，群聊详情仍保留相关入口。
- 点击齿轮进入设置后，不再重复显示头像和名字，同时保留顶部分享、设置和关闭三个按钮。
- 补全右侧分隔线顶部缺口，修复头像背景尺寸、偏位和编辑笔常驻的问题；桌面端悬停或聚焦时显示编辑入口，触屏保留可发现的入口。

## 十、头像和名字可以直接修改

- 在右侧面板直接点击头像即可编辑，点击头像下方名字即可改名；回车或移开焦点保存，Esc 取消。
- 上传头像保留完整画面范围，并支持 100%～400% 缩放、上下位置调节、拖动取景、滚轮缩放及重置。
- 支持圆形、圆角和方形显示，保存与备份保留取景参数。
- 设置 → 通用新增“我的头像”，可修改左下角个人头像或恢复默认。
- 旧版已经裁掉的图片部分无法自动恢复，需要重新上传原图；上传的 GIF 头像保存为静态图。

## 十一、窗口与侧栏细节优化

- 调整搜索、新建、中间智能体按钮、右侧工具按钮与连接应用入口的尺寸、对齐、顶部留白和间距。
- 中间按钮的小三角只在悬停、键盘聚焦或详情展开时出现。
- 修复两侧伸缩边缘悬停时线条过粗的问题，保留拖动调宽、宽度记忆、展开收起过渡和窄窗口适配。
- 优化窗口最小化、最大化／还原和关闭图标及关闭悬停效果，继续由 PI Desktop 处理窗口操作。
- 调整顶栏拖窗区域，避开可点击控件；关闭左侧智能体头像的悬停动作。
- 收窄并优化输入区宽度、阴影和圆角，调整窄窗口下的消息操作，避免内容超出边界。

## 十二、工作经验入口更简洁

- 工作经验与复盘经验收纳进消息“…”菜单，不再长期占据聊天区域。
- 尚无消息时，可从左侧 Bot 列表右键菜单进入。
- 保留经验建议审批、待处理状态、失败提示及私密内容共享确认。

## 使用说明

- 图片理解需要所选模型支持视觉；能显示图片预览不等于模型一定能识图。
- 新建 Bot 的后台个性化开场会调用所选模型，可能产生相应模型费用。
- 应用授权继续使用用户自己的 Composio 项目和第三方账号；本次更新不提供公共授权服务器。
- “电脑”页使用 PI Desktop 已有能力，不新增独立浏览器内核；“资料库”整理现有内容，不新增云端知识库存储。
- 本次检查包含本地回归、模拟界面测试和安装包校验；真实模型、第三方账号、麦克风和原生窗口的表现仍与用户环境有关。

更新后请重载 PI Bot 插件或重启 PI Desktop。
