# PI Bot 0.3.85

对照 DS Bot 0.2.1 源码，将适合 PI Desktop 的功能逐项适配到现有插件，保留已有头像、语音设置、附件、权限和增量流式消息机制。

## 新增功能与入口

- **独立侧问**：在 Bot 私聊输入 `/btw 你的问题`。根据当前对话快照单独回答，不中断主任务、不执行工具、不写进主聊天上下文。侧问显示为独立卡片，支持取消、关闭和重启后查看已完成答案。侧问调用所选 Bot 的模型，会产生正常模型用量；不是额外免费模型。
- **图表与计算卡片**：请 Bot 使用 `show_view` 展示柱形图、横条图、折线图、面积图或环形图，或生成滑块、数字、开关、选项和公式计算器。拖动时在本地更新数字和图表，点击提交后将声明的输入交回 Bot；保留原有表格、确认、多选和表单。
- **消息外观**：打开左下角设置 → Bot 设置 → 通用 → 外观，可切换气泡/平铺布局，调整气泡宽度和正文宽度（50–100%），打开“显示思考过程”。默认隐藏思考只改变界面显示，不等于关闭模型思考。
- **群聊继续**：群内文字 `@成员` 自动交接到达限制时保存待办，输入框上方显示“继续”。点击继续或发送新消息可恢复。群详情可设置自动交接上限，默认是成员数 × 3；循环呼叫同样暂停并保留待办。跨群发起讨论、私聊 `message_bot` 等工具仍保留既有安全限制。
- **密钥用途**：设置 → 密钥，可以修改或清空用途备注，无需再次填写密钥；修改密钥值及加密迁移会保留备注。

示例：`请使用 show_view 给我一个预算计算器，包含单价滑块、数量输入、总价指标和费用图表。` 卡片由模型通过工具创建，是否生成取决于模型的工具调用能力。

## 稳定性与交互

- 记忆文件或主题目录存在但无法读取时停止修改，保留原文件；正常聊天提示记忆暂不可用，恢复文件访问后重试读取。
- 群内文字交接队列与已创建任务一起保存，失败时回滚；重复继续不会重复派发已经接收的任务，删除成员时清理关联待办。
- Bot 等待队友时继续显示工作状态。思考内容启用后显示在回复上方。
- Bot 详情与 PI 原生工作区面板互斥；工作区入口仅在宿主提供对应按钮时显示。本版不新增未经验证的“新建终端”接口。
- 窄窗口详情覆盖聊天、设置填满窗口；触屏点消息可显示工具，控件兼顾安全区域。
- 交互卡片维持 8 KiB 蓝图限制、答案校验、重复提交保护和已保存答案的失败重试；公式使用解析器，不执行任意 JavaScript。图表可查看数据表、导出 CSV 和 SVG。

## 平台适配边界

- HTML 卡片采用**静态隔离展示**：iframe 使用空 sandbox，不允许脚本、同源访问、网络请求、表单提交或页面跳转。交互请使用声明式输入与公式；未迁移上游执行自定义脚本的模式。
- PI 的一次性模型补全接口没有公开的取消参数。取消侧问会停止接收答案并标记卡片，底层请求可能仍在宿主执行并产生用量；宿主超时与限流继续适用。
- 未迁入上游独立客户端的 Linux 安装器、DeepSeek 账户退出、读取本机浏览器 Cookie、原生下载保存对话框等功能；不代表新增 Android、macOS 或 Linux 兼容性。
- 下载功能受 PI Desktop 的 renderer 下载策略影响；浏览器自动化已验证导出内容，未声称所有宿主版本都弹出保存位置对话框。

## 升级

安装 `local.pi-bot-0.3.85.piplug`，然后重载插件或重启 PI Desktop。插件 ID、权限声明、原有数据目录不变，不携带作者的 Bot、聊天或凭据。`PI-bot-0.3.85.piplug` 是给旧版更新检测使用的同内容兼容包，只需安装一个。使用同一 Release 的 `SHA256SUMS.txt` 校验文件。

自动化验证覆盖存储故障、重启、群交接、侧问隔离、密钥元数据、公式校验，以及真实 Chromium 的点击、主题、窄窗口和 HTML 沙盒。另通过 PI 原生安装器的临时数据目录安装校验；没有覆盖用户当前安装，也未使用用户的真实模型额度进行端到端调用。

GitHub Release 与 PI Desktop 插件市场独立，市场需要另外提交新包。
