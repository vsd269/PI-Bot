# PI Bot 0.3.100

本版整理右侧详情面板，并补全上传头像的取景控制。

- **直接修改头像和名字**：打开 Bot 右侧详情，点头像即可编辑；点头像下方名字可直接输入，回车或移开焦点保存，Esc 取消。齿轮仍用于其他设置。
- **头像取景**：保留上传图片的完整画面范围（压缩后存储），支持 100%–400% 缩放、上下位置滑条、拖动取景、滚轮缩放和重置位置。圆形／圆角／方形立即预览，保存及备份保留取景参数。历史版本已裁掉的部分需重新上传原图才能恢复。
- **资料库**：右侧新增“详情／资料库／电脑”三个标签。资料库集中展示“它记住了什么”、技能和工作文件夹；技能入口默认选中当前 Bot。资料库管理已有能力，不额外创建文件索引或云端存储。
- **电脑**：浏览器、工作区与终端和 PI 原生会话统一收纳到此；移除聊天顶栏的工作区按钮。群聊详情保留工作区与终端入口。使用 PI Desktop 原生会话和侧栏，保留动画、宽度拖动及失败提示。
- **分隔线**：补全右侧详情分隔线到窗口顶部，保留按钮和内容的原有高度及拖动调宽。
- **界面**：详情顶部依次为分享、设置、关闭三个 34px 按钮，统一 10px 间距；头像编辑和资料库卡片按照参考界面调整。

## 验证范围

使用隔离数据检查改名保存／取消／失败、头像完整范围和取景保存、设置表单／共享库／备份兼容、资料库目标 Bot、原生侧栏模拟动画和拖动，以及明暗与窄窗口布局。不改动实时用户会话、模型或密钥；模拟界面检查不等于真实 PI Desktop 运行验收。

## 安装

桌面安装包：`local.pi-bot-0.3.100.piplug`。保留旧版本，安装后重载插件或重启 PI Desktop。本轮未发布 GitHub。
