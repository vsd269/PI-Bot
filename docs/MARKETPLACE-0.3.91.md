# PI Bot 0.3.91 更新说明

- 修复管理员计划格式异常或重复分派导致整轮任务失败的问题，支持一次自动纠正，失败时保留原回复并说明具体原因。
- 优化后台检查与状态保存，减少无变化时的重复处理，保留原有流式观察频率。
- 定时任务增加执行全过程记录与防重叠处理，等待用户、审批或队友时可查看原因。
- 新增文件条件等待：工作目录内文件出现或变化后再执行，支持取消与到期。需要 PI Desktop 保持运行。
- 增加工具重复失败提示及工作摘要，便于查看执行过程和未核对事项。
- 自动记忆增加用户原话来源校验，并可定位原消息。
- 新增团队配置模板，支持预览后导入；不携带聊天、记忆、密钥和授权，导入的自动化默认暂停。
- 加强进程锁身份判断和交接来源标记，提高任务恢复与协作的可靠性。

安装更新后，请重载插件或重启 PI Desktop。
