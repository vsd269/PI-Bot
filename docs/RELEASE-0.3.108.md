# PI Bot 0.3.108

基于用户提供的 0.3.107 源码构建的本地修复版。插件 ID 保持 local.pi-bot。

## 本次修复

1. 请求不再按创建时间在两分钟后被清理。持续读取会续期；完成分块允许重复读取，减少传输重试时的失效。异常任务不自动重新执行。
2. 大状态响应协商 gzip 压缩，降低长聊天、头像等数据通过受限桥接传输的等待。停止、回答、发送和已读确认优先处理。
3. 管理员规划回合加入流式展示，只显示可读 reply 内容；成员输出仍按 sessionId/turnId 隔离显示，忽略重复子代理消息。未提供 turnId 的事件仅在存在唯一已接收回合时按时间匹配。
4. 规划、排队、私聊处理期间显示工作状态，规划回合采用更及时的界面刷新。
5. 群聊停止先冻结旧分派代次，同时发出原生中断和保存，避免等待保存才中断。重复停止终态任务不再抛出 No active task to interrupt；若原生仍运行同一回合，会按准确身份补发停止。保留宿主对工具中断的约束。
6. 群聊 System 提示以该群管理员的名称、头像和颜色展示，并兼容旧记录。
7. 群聊结果只标群聊未读，不再误标成员私聊；已读确认会抑制旧轮询快照恢复的标记，仍允许手动标未读。折叠侧栏的圆点位置保持头像右下角。
8. @ 列表包含群管理员；@ 管理员进入管理员规划路径，不把管理员当普通执行成员派单。串行和并行设置均保留。
9. 原生 Ask 工具通过 PI 的公开 pendingInteractive 与 askToolResolve 预加载接口在 PI Bot 内显示并回答，支持恢复待答卡、多题、描述、单选/多选、自定义文本、跳过及整组拒绝。全部作答后恢复原来的工具，不新建任务。
10. 图片预览按钮改成四角展开图标。

## 更新

在 PI Desktop 插件页导入 local.pi-bot-0.3.108.piplug。相同插件 ID 使用原数据目录；不要先删除插件数据。正常更新不会把机器人设置写入插件包。
建议更新前停止正在运行的任务，并使用 PI Bot 的备份功能导出一份。更新后若界面版本仍未变化，在插件页重载插件或重启 PI Desktop。

跨电脑传输安装包即可安装插件代码。要带走自己的 Bot 设置和聊天，另用插件的备份/恢复；密钥使用原有的加密迁移导出功能。源码压缩包用于继续开发，不用于插件页导入。

## 验证范围

使用隔离测试数据与模拟模型验证实时输出、提问卡及任务路由；另用本机 PI Desktop 0.22.0 的插件进程和原生安装器验证加载与安装。不调用真实模型，不修改真实用户数据或正在运行的任务。真实模型首字延迟、网络、工具本身的停止速度仍由宿主和服务端决定。
