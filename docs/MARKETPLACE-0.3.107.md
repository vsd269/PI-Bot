PI Bot 0.3.107｜汇总 0.3.102–0.3.107 更新

本次更新新增侧栏分类与拖动排序，增强记忆检索，并集中优化消息交互、停止操作和界面细节。

- 新增“群组聊天”分类和自定义部门，Bot、群聊都能分类整理，支持数量显示、折叠、改名和删除；删除部门保留会话与聊天记录。
- 支持拖动会话调整顺序、跨部门移动；分类、排序和折叠状态保存后重启仍保留，主机器人固定在顶部。
- 会话行悬停显示三个点，可直接打开操作菜单；右键新增“移至部门”，左上角加号可创建空部门。折叠部门内的会话仍可搜索。
- 增强长期记忆检索：先查看简短索引，再按需读取具体内容；历史消息支持前后文回看，保留私密内容的访问限制。
- 消息表情添加、切换和移除即时反馈，保存不再阻塞界面；修复连续操作时表情跳回的问题，保存失败会恢复并提示重试。
- 调整消息旁表情、回复、更多三个图标的大小与圆形悬停效果，保留原有菜单、引用和时间显示。
- 修复执行中、正在回复等状态重复显示的问题，实时状态更清楚。
- 补齐私聊执行时右下角的停止按钮，空输入框也能停止任务；点击后立即显示正在停止，失败可重试，保留草稿与已有回复。
- 聊天顶栏改为透明渐变，消息可滚到中间 Bot 按钮后方，边缘柔和淡出，适配浅色与深色模式；保留窗口拖动、侧栏调整和聊天查找。
- 左侧滚动条默认隐藏，鼠标进入侧栏后显示细线，移到滚动条上或拖动时加粗；修复分隔线拖动区域遮挡滚动条的问题。
- 优化管理员卡片下方和列表底部的渐隐效果，加深群组聊天与部门标题，最后一条会话可完整滚动显示。
- 修复密钥用途保存按钮文字折行、错位，提升分类与表情保存失败时的恢复体验。

更新后请重载 PI Bot 插件或重启 PI Desktop。
