# PI Bot 0.3.90 · 可靠续跑、待处理与群聊控制优化

本次更新集中改善多人任务的接续、异常处理和群聊操作体验。

## 新增与改进

- **待处理页面**：在插件设置中集中查看用户问题、经验提案、原生审批入口、运行异常，以及已完成待查看的任务，减少在多个聊天之间寻找待办。
- **任务先保存，再执行**：完善任务续跑、问题回答、队友结果转交和群聊批次的保存流程；保存失败时不启动本次任务，提交状态不确定时保留记录并提示核对，减少重复派发。
- **多人结果回收**：成员完成任务后，总控沿用原群聊规划会话收集结果，必要时继续安排原任务尚缺的步骤；仍在等待用户回答的任务不会被当作已经完成。普通问候不额外触发结果回收调用。
- **原发送键切换为停止键**：群聊运行时可在输入框右侧直接停止本群，结束后恢复发送状态，不额外增加按钮；保留输入草稿，不影响其他聊天。
- **取消固定交接次数上限**：正常群内文字交接不会因达到 18 次而暂停；连续无工具操作的确认或重复内容才触发空转保护，保留待办，可由用户继续。
- **团队数据冲突保护**：检测到外部修改时保留双方数据副本，暂停自动派发，并提供核对与恢复入口，降低旧数据覆盖当前名单和设置的风险。
- **稳定性与界面细节**：优化自动记忆整理容错、群设置保存、带引号的 Bot 名称识别、长群规划资料处理和历史用量补扫；工作经验标题与复盘按钮相邻排列。

## 在哪里使用

- 左下角头像 → 插件设置 → **待处理**。
- 群聊运行中 → 输入框右侧原发送键位置的 **方块停止键**；群详情中的全部停止入口仍保留。
- 检测到空转暂停时 → 输入框上方 **继续**，或发送新消息。
- Bot 私聊 → **工作经验**标题旁的 **复盘经验**。

## 更新方式

下载 `local.pi-bot-0.3.90.piplug`，在 PI Desktop 中安装更新。`PI-bot-0.3.90.piplug` 是兼容旧更新入口的同内容文件，只需安装其中一个。`SHA256SUMS.txt` 可用于核对下载完整性。

建议更新前导出个人备份。更新后请重载 PI Bot 插件或重启 PI Desktop。

- 安装包完成内容、CRC 与 SHA-256 校验。本地市场预检仅覆盖已知阻断模式，不代表官方市场审核结果。
- 停止不会撤销已经完成的文件修改。提交状态不明确时需打开原生会话核对；本地去重不保证外部操作绝对只发生一次。
- 自动结果回收仍使用管理员所选模型并计入用量；必要后续最多自动安排两批，不会无限自动扩展任务。
