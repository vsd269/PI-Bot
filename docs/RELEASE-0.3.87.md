# PI Bot 0.3.87：执行层首批可靠性补丁（本地候选版）

以用户指定的 0.3.86 为基线。本版是分阶段改造中的第一批补丁，尚未通过真实 PI Desktop/模型验收，未发布到 GitHub 或插件市场。

## 这次能改善什么

- Bot 使用带 request_id 的 message_bot 派发给执行者时，任务与接收确认一并保存，保存完成才启动；相同编号重试不会创建第二个执行者任务。
- 中途保存失败或重启时，能够核对原派发是否已经创建任务；结果未知时不会悄悄重派。
- 恢复中心可以查看最近的执行状态变化，帮助区分排队、执行中、中断和结果交回。
- Bot 可按需通过 check_delegation 查询自己发出的任务；仍使用原来的自动结果回交。

## 在哪里查看

PI Bot 左下角设置 → 设置页面的“关于” → “PI 扩展” → “任务恢复中心” → 待核对任务卡片上的“执行记录”。这里是排障入口，已完成且不需要恢复的任务不增加新看板。

## 安装与限制

先导出完整备份，再通过 PI Desktop 导入 `local.pi-bot-0.3.87.piplug`，重载插件或重启 PI Desktop。安装包 ID 仍为 local.pi-bot，不与旧包同时启用。

本版没有增加模型规划/审核回合，没有更换原生权限，也没有重写普通私聊/群聊的流式呈现。管理员规划分支与旧无编号调用保留原机制，不承诺所有任务入口和外部操作只执行一次。任务“完成”不等于成果已通过独立验收。

只保留最近 512 条元数据状态变化，不记录正文或密钥；不是永久审计。未知外部操作仍需要先核对再手动继续/重试。

完整评估、后续计划和测试范围分别见 `EXECUTION_ENGINE_AUDIT.md`、`EXECUTION_ENGINE_PLAN.md`、`EXECUTION_ENGINE_TEST_REPORT.md`。
